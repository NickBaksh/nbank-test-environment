Чек лист проверки по второй итерации проверки API NBANK
Итерация 2:
1. Депозит денег пользователем
2. Перевод денег с одного аккаунта на другой
3. Изменение имени пользователя



Предусловия
=================
1. Авторизация под учетной записью админа, чтобы получить токен авторизации
2. Создание учетной записи первого клиента (Кейт)
3. Создать учетной записи второго клиента (Алекс)
4. Создание 2х аккаунтов для клиента Кейт
5. Создание одного аккаунта для клиента Алекс

Проверки
=================
Проверка размещения депозита на аккаунте:
1. Размещение суммы -1 на депозите Кейт --> 400 Ошибка
2. Размещение суммы 0 на депозите Кейт --> 400 Ошибка
3. Размещение суммы 1 на депозите Кейт --> 200 Успех 
4. Размещение суммы 4999 на депозите Кейт --> 200 Успех
5. Размещение суммы 5000 на депозите Кейт --> 200 Успех
6. Размещение суммы 5001 на депозите Кейт --> 400 Ошибка
7. Размещение депозита на чужой аккаунт --> 403 Ошибка
8. Размещение депозита на несуществующий аккаунт --> 403 Ошибка

Проверка перевода денег с одного аккаунта на другой:
1. Перевод денег на сумму -1 на другой аккаунт (Кейт -> Алекс) --> 400 Ошибка
2. Перевод денег на сумму 0 на другой аккаунт (Кейт -> Алекс) --> 400 Ошибка
3. Перевод денег на сумму 1 на другой аккаунт (Кейт -> Алекс) --> 200 Успех
4. Перевод денег на сумму 9999 на другой аккаунт (Кейт -> Алекс) --> 200 Успех
5. Перевод денег на сумму 10000 на другой аккаунт (Кейт -> Алекс) --> 200 Успех
6. Перевод денег на сумму 10001 на другой аккаунт (Кейт -> Алекс) --> 400 Ошибка
7. Перевод денег на сумму 0.1 на другой аккаунт (Кейт -> Алекс) --> 200 Успех
8. Перевод денег на сумму > суммы на аккаунте (Кейт -> Алекс) --> 400 Ошибка
9. Перевод денег между своими аккаунтами на сумму 1 (Кейт -> Кейт) --> 200 Успех
10. Перевод денег на несуществующий аккаунт (Кейт -> ???) --> 400 Ошибка
11. Перевод денег без авторизации --> 401 Ошибка
12. Перевод денег на сумму 1000 на другой аккаунт (Алекс -> Кейт) --> 200 Успех
13. Перевод денег на сумму 1 с авторизацией на Кейт, но с аккаунта Алекса (Алекс -> Кейт) --> 403 Ошибка
14. Перевод денег на сумму 1 на тот же аккаунт (Кейт -> Кейт) --> 400 Ошибка (Нелогичное поведение)

Проверка изменения имени профиля:
1. Изменить имя профиля (Кейт) на "Екатерина Великая" --> 200 Успех
2. Изменить имя профиля (Кейт) на "Екатерина Великая Александровна" --> 400 Ошибка
3. Изменить имя профиля (Кейт) на "Екатерина" --> 400 Ошибка
4. Изменить имя профиля (Кейт) на " " --> 400 Ошибка
5. Изменить имя профиля (Кейт) на "Екатерина12 Великая" --> 400 Ошибка
6. Изменить имя профиля (Кейт) на "Екатерина Великая12" --> 400 Ошибка
7. Изменить имя профиля (Кейт) на "Екат&рина Великая" --> 400 Ошибка
8. Изменить имя профиля (Кейт) на "Екатерина Велик@я" --> 400 Ошибка
9. Изменить имя профиля (Кейт) на "Екатерина_Великая" --> 400 Ошибка
